# Flask Oracle App

A lightweight Flask web application connected to an Oracle 11g database. This project provides a basic starting point for building scalable and secure applications using Flask and Oracle Database.

## 📦 Features

- 🐍 Built with Python and Flask
- 🗄️ Oracle 11g database integration
- 📁 Modular project structure
- 🧪 Ready for testing and extension
- 🔐 Uses `.env` for configuration

## 🏁 Getting Started

### Prerequisites

- Python 3.8+
- Oracle 11g or Oracle Instant Client
- `cx_Oracle` Python package
- Virtual environment (recommended)

### Installation

```bash
# Clone the repo
git clone https://github.com/yourusername/flask-oracle-app.git
cd flask-oracle-app

# Set up virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
